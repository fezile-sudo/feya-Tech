# FEYATECH - Ecommerce Web Application

![FEYATECH Logo](https://via.placeholder.com/1200x400?text=FEYATECH+Ecommerce)

## Overview

FEYATECH is a modern ecommerce web application built with React.  
The application provides a complete shopping experience including product browsing, product details, reviews, wishlist management, cart functionality, user authentication, and checkout flow.

This project was built as a full frontend ecommerce solution and is structured to be extended with a Node.js, Express, and MongoDB backend.
